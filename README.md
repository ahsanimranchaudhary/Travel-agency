Travel Agency

A small web application for a travel agency, built with PHP, MySQL, HTML and CSS. Users can create an account, log in securely, and browse upcoming trips on a protected home page.

This is a university web development project. The current version covers authentication and the full database schema. Booking, payment and review features are planned (see Roadmap).

Features
Sign up with full name, email and password, with server-side validation
Login with email and password, then redirect to the home page
Protected home page that lists upcoming trips from the database
Logout that fully destroys the session
Role column (user / admin) stored in the session, ready for admin features
Complete database schema for trips, itineraries, guides, bookings, payments and reviews
